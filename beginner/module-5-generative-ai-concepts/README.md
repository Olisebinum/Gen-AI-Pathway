# Module 5: Understanding Generative AI – Concepts and Applications

**Level:** Beginner | **Duration:** 3 Weeks

## Learning Outcomes
- Generative Models: GANs, VAEs, Autoregressive Models
- Probability distributions used in generative models
- Likelihood and Maximum Likelihood Estimation (MLE)
- Loss functions, mode collapse, transfer learning in generative models
- Applications: image generation, style transfer, text generation, drug discovery, anomaly detection
