# Module 1: Advanced Machine Learning Techniques

**Level:** Intermediate | **Duration:** 2 Weeks

## Learning Outcomes
- Deep Learning (DNNs, multi-layer architectures)
- Reinforcement Learning
- Ensemble Learning (Random Forests, Gradient Boosting)
- Transfer Learning
- Semi-Supervised and Self-Supervised Learning
- Generative Adversarial Networks (GANs)
- AutoML and Hyperparameter Optimization
- Time Series Forecasting with RNNs
- Meta-Learning (MAML)
- Explainable AI (LIME, SHAP)

## Resources
- [Understand Machine Learning – Microsoft Learn](https://learn.microsoft.com/en-us/training/paths/understand-machine-learning/)

## Deliverable
Train models demonstrating understanding of **at least 2** of the listed techniques.
