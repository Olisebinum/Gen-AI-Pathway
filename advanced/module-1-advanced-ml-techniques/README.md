# Module 1: Advanced Machine Learning Techniques

**Level:** Advanced | **Duration:** 2 Weeks

## Learning Outcomes
Same scope as Intermediate Module 1, applied at an advanced level:
- Deep Learning, Reinforcement Learning, Ensemble Learning
- Transfer Learning, Semi-Supervised / Self-Supervised Learning
- GANs, AutoML, Hyperparameter Optimization
- Time Series Forecasting with RNNs
- Meta-Learning (MAML)
- Explainable AI (LIME, SHAP)

## Resources
- [Understand Machine Learning – Microsoft Learn](https://learn.microsoft.com/en-us/training/paths/understand-machine-learning/)

## Deliverable
Train models demonstrating understanding of **at least 2** techniques at an advanced level.
